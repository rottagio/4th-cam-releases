# 4TH CAM — Atualizações oficiais

Este repositório é usado exclusivamente para distribuir versões do **4TH CAM** para Windows.

- Não contém o código-fonte do aplicativo.
- Não contém contas, senhas, configurações, tokens ou dados das câmeras.
- Os pacotes publicados são validados pelo atualizador antes da instalação.

A versão mais recente está disponível na seção **Releases**.
